本站是 Histology Guide 的非官方中文学习改编版，与 Histology Guide 无隶属关系、未经其认可或背书。原始图像与文字版权归 Histology Guide 及/或原始贡献者所有；本站按作者 2026-10-20 书面许可公开托管，仅限非商业教育用途并免费访问。

在线访问（推荐）

公开地址：https://blog.acretiondisk.top/histology-guide-zh/。无需安装，直接用浏览器打开；学习进度只保存在你自己的浏览器里。

本地打开与重新生成

项目克隆到本机后，也可直接打开或本地起服务：

  1. 直接打开：双击 site/index.html，用浏览器打开即可（Chrome / Edge / Firefox / Safari 均可）。所有数据随页面内嵌，离线可用。
  2. 本地静态服务器（可选）：在项目根目录运行 npx serve site 或 python -m http.server 8080 -d site，再访问 http://localhost:8080。

目录结构与重新生成

scripts/fetch.mjs        元数据采集（限速 / 可增量 / 遵守 robots）
scripts/scaffold.mjs     汇总 inventory + 生成内容脚手架
scripts/check-content.mjs 校验中文内容与术语一致性
scripts/fetch-images.mjs 按书面许可下载所选图像的概览层级（可增量）
scripts/stitch_tiles.py  本地拼接瓦片（Pillow）
scripts/build.mjs        生成 site/ 静态页面与内嵌数据
content/zh/chapters/     每章中文内容 JSON
content/zh/terms.json    术语表
data/inventory.json      章节 / 小节 / 标本清单
data/local-images.json   本地图像清单（含来源、尺寸、SHA-256、署名）
site/                    生成后的网站（可直接打开）

重新生成：node scripts/fetch.mjs → node scripts/scaffold.mjs → node scripts/build.mjs；图像：node scripts/fetch-images.mjs --per-chapter=1（可断点续跑，已存在则跳过）。
